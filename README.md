### 🏗️ Project Architecture

This is a **monorepo** containing both the frontend and backend:

```
shihadahmed/
├── frontend/                 # Next.js 14 (App Router)
│   ├── src/app/              # App Router pages
│   │   ├── (main)/           # Route group
│   │   │   ├── page.js       # Home
│   │   │   ├── projects/     # Projects listing & detail
│   │   │   ├── skills/       # Skills page
│   │   │   ├── experience/   # Experience timeline
│   │   │   ├── blog/         # Blog listing & posts
│   │   │   └── testimonials/ # Testimonials
│   │   ├── layout.js         # Root layout
│   │   └── globals.css       # Global styles + design tokens
│   ├── src/components/       # Reusable components
│   ├── src/lib/              # Data, constants, utils
│   └── public/               # Static assets
│
├── backend/                  # Express.js + MongoDB Atlas
│   ├── src/
│   │   ├── models/           # Project, Skill, Experience, Testimonial, Blog, Contact
│   │   ├── routes/           # Full CRUD REST APIs
│   │   ├── config/           # MongoDB connection
│   │   └── middleware/       # Error handling
│   ├── .env                  # Local config (gitignored)
│   └── .env.example          # Template for MongoDB Atlas URI
│
├── .gitignore
├── SPEC.md                   # Project specification
└── README.md
```

### 🚀 Quick Start

#### Prerequisites
- Node.js 18+
- MongoDB Atlas account
- Git

#### 1. Clone & Install
```bash
git clone https://github.com/shihadahmed/shihadahmed.git
cd shihadahmed

# Frontend
cd frontend && npm install

# Backend
cd ../backend && npm install
```

#### 2. Configure Environment
**Backend** (`backend/.env`):
```bash
cp .env.example .env
# Add your MongoDB Atlas URI to MONGODB_URI
```

**Frontend** (`frontend/.env.local`):
```env
NEXT_PUBLIC_API_URL=http://localhost:5000/api
```

#### 3. Run Development
```bash
# Terminal 1 - Frontend
cd frontend && npm run dev
# → http://localhost:3000

# Terminal 2 - Backend
cd backend && npm run dev
# → http://localhost:5000
```
